# Amor de Princesa

Proyecto Android creado desde cero para la tienda online Amor de Princesa.

Incluye 23 pantallas, área cliente, área administrador, catálogo, filtros, detalle, variantes, carrito, entrega, medios de pago demo, confirmación, gestión de productos, pedidos, clientes, ventas, notificaciones y configuración.
